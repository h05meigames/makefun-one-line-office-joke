One-line office joke generator: writes a single-line joke about office life to `/output/entry.txt`.

## What it does

`main.ts` writes exactly one joke — the sort of line you send a colleague after a meeting that should have been an email — to `/output/entry.txt`. The joke is a single line of at most 200 characters, with no newline or control characters. No dependencies, no network access, deterministic output: every run writes the same line.

## Run it

```sh
node main.ts
```
